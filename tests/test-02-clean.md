# Резервное копирование

## Порядок работы

1. Остановите приложение.
2. Скопируйте каталог данных в резервный каталог.
3. Проверьте копию: размер файлов должен совпадать с исходником.
4. Запустите приложение.

При ошибке копирования агент записывает сообщение в журнал и повторяет шаг 2. Если повтор не помог, обратитесь к администратору.

Возможно, потребуется увеличить дисковую квоту. Тогда подойдёт внешнее хранилище.
