# История изменений

## 1.0.2-ru — 2026-10-31

- Добавлен `INTEGRATION.md`: готовый блок для пользовательских файлов инструкций (ZCode `~/.zcode/AGENTS.md`, Claude Code `~/.claude/CLAUDE.md`) — ядро стиля, линт-проход объёмных документов и различение режимов для включения глобального поведения во всех сессиях.
- `README.md`: раздел о глобальном поведении, обновлена структура репозитория.

## 1.0.1-ru — 2026-10-30 (адаптация под ZCode)

- Линтер принудительно переключает stdin/stdout/stderr в UTF-8: кириллица больше не искажается при запуске через пайп Windows-консоли (Git Bash, агентские среды).
- `SKILL.md`: добавлены ссылки на материалы скилла; запуск линтера описан через полный путь к каталогу скилла (относительный путь не работает в агентских средах); указано, что на Windows команда — `python`, а не `python3`.
- `README.md`: добавлены инструкции установки для ZCode (`~/.agents/skills/`, вызов `/asd-ste100-ru`).
- Приёмка поставки: все 10 файлов свёрены по SHA-256 с манифестом, `--selftest` проходит.
- Формат вывода усилен по результатам тестового прогона: список исправлений — только по явному запросу.
- Границы дополнены по результатам второго прогона: не разрешать двусмысленность источника молчаливым выбором одного чтения.
- Различение режимов по результатам третьего прогона: в обычных объяснениях — ядро стиля; разбор «Правило | До | После» уместен, когда пользователь сигнализирует о непонимании текста; дублирующий «упрощённый вариант» и упоминание линтера — только по запросу.

## 1.0.0-ru — 2026-10-30

- Создан русскоязычный `SKILL.md` для агентских текстов: два режима, сохранение модальности, правила и формат вывода.
- Создан справочник из 18 тематических правил адаптации с делением на hard/advisory/manual.
- Реализован Python-линтер для кириллицы без сторонних зависимостей; сохранены CLI-флаги и коды завершения, добавлен выбор режима.
- Перенесены механизмы Markdown-блоков, таблиц, inline/fenced code, цитат и GitHub-алертов.
- Созданы русские пары «до/после» и регрессионная фикстура.
- Добавлены тесты для каждого автоматического правила, хеджей и пограничных случаев.
- Выполнена стартовая калибровка на четырёх русскоязычных источниках документации (148 слов, 0 предупреждений на выбранных фрагментах).
- Официальный текст и словарь ASD-STE100 не воспроизводятся; в README указаны ограничения и правовой статус адаптации.
